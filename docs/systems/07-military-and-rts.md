# 系统规格：军事与 RTS

## 数据层级
UnitRecord（逻辑单位）→ SquadRecord（小队）→ ArmyGroupRecord（编队）。逻辑单位 ID 不随 Entity 加载/休眠变化。

## 首发范围
M4 首批：民兵、基础步兵、弓箭手；骑兵和攻城器械可后续加入。兵营负责训练队列、人口/资源扣除和完成时间。

## 命令
Move、AttackTarget、DefendPosition、Follow、Patrol、Rally、Retreat、Escort。命令有 ID、下达者、目标、优先级、状态和创建时间。

## 服务器权威
客户端只能请求选择/下达命令。服务器验证所有权、视野、目标有效性、距离、命令速率和部队状态。客户端不决定命中、伤害或战斗胜负。

## 实时/抽象战斗
附近战斗用实体；远程战斗用 BattleSnapshot。切换时冻结一侧并原子应用另一侧，避免重复结算。单位伤亡和资源掠夺按 BattleResult ID 幂等提交。

## 验收
小队可移动和撤退；断线重连后命令状态合理；同一个战斗结果不重复扣兵；远程转实时前后军队数量/状态连续。
